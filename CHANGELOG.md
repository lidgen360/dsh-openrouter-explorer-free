# Changelog

## 0.1.0 — 2026-11-08

- Первый выпуск плагина: вкладка **«Модели OpenRouter»** в правой боковой панели DSH.
- Каталог моделей OpenRouter с ценами входа/выхода (`$ / 1M токенов`), контекстом, модальностью,
  `:batch`/`:free`-вариантами и `pricing.overrides`.
- Автообновление раз в 24 часа: `next_sync_at` в состоянии, тик 5 минут, повтор через час после сбоя сети.
- Бесплатные модели: KPI, фильтр и события «стала бесплатной»/«больше не бесплатная».
- Скидки: сравнение с предыдущим замером и максимумом за 30 дней (порог 30%), журнал событий,
  бейджи «−N%», batch и «тариф по расписанию».
- Суперкнопка **«Едем на халяву»**: бесплатная chat-модель с максимальным контекстом → реальный пинг
  (`chat/completions`, батчами по 3) → добавление модели в каталог провайдера OpenRouter через
  `ctx.configEditor` → переключение текущей сессии.
- HTTP API: `status`, `models`, `events`, `settings`, `events/read`, `sync`, `auto-route`.
- Тесты: `node --test tests/` — нормализация цен, бесплатность, история, скидки, baseline, события,
  сбой синка, single-flight, auto-route (без сети).
- Ключ OpenRouter читается только из DSH-credentials/окружения по ссылке `OPENROUTER_API_KEY`;
  в репозитории секретов нет.
